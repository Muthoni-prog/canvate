# Glass Box Food Security Agent

Food insecurity often comes from a gap in decisions, not just a shortage of food. Relief workers and local officials must decide where to send limited aid, but spreadsheets can miss patterns and many AI systems give answers without reasons.

This project uses MeTTa to compare food supply, local needs, and risk factors (crop failure, price spikes, distance to markets) against explicit rules, and flags which communities face the biggest gap. Every ranking comes with its full reasoning trail, so decision-makers can check it, challenge it, and trust it before acting.

Note: This is a hackathon prototype using sample data. It is decision support, not a replacement for expert or on-the-ground judgment.

Built for the State of the Art Hackathon, Glass Box Agent challenge (MeTTa Foundation track).
