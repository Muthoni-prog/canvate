# AI disclosure

Using AI is allowed in this hackathon. Hiding it is not. This file lists every AI tool the team used and what it was used for. The team keeps it up to date.

## Tools used

| Tool | What it was used for |
|---|---|
| Claude (Anthropic) | Brainstorming the project idea and planning the build. Drafting and debugging `rules.metta`and  `run.py`. Reviewing the project against the hackathon rules and judging criteria. |


## What the AI does inside Glass Jury

Nothing. Glass Jury does not use machine learning or a language model to make decisions. Every verdict, score and reason is produced by explicit MeTTa rules (`rules.metta`) applied to facts (`data.metta` or an uploaded CSV). Nothing is sent to an AI service at run time, and no API key is needed.

## What the team did

- Chose the track and challenge, the four criteria, the three hard gates and the default weights and threshold.
- Wrote the synthetic sample data. No real artists, HFAS, AI for Peace or Incantio works are used.
- Reviewed, ran and tested all code, data and documentation before submitting.
- Recorded the demo video.
